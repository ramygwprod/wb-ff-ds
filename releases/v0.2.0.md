# v0.2.0

**Date:** 2026-11-08, 01:20 EET (UTC+02:00)
**Goal achieved:** the pipeline foundation. The `wb-ff-ds` library builds, dependencies are hardened against supply-chain attacks, linting enforces code and template-accessibility rules, and CI checks every PR. No tokens or components yet.

## Added
- **Library project `wb-ff-ds`** (`projects/wb-ff-ds`), from `ng generate library`, without Angular's sample component. It exports nothing yet. `ng build` outputs to `dist/wb-ff-ds`. Selector prefix: `lib` (Angular's default).
  - New dev tools: `ng-packagr`, `@angular/build`, `vitest`, `jsdom`.
- **Linting:** `angular-eslint` 22.6.0 via `ng add` (`eslint.config.js` at the root and in the library, `ng lint`, `npm run lint`). Rules: ESLint recommended, typescript-eslint recommended + stylistic, Angular recommended, template recommended, and **template accessibility**.
- **CI** (`.github/workflows/ci.yml`), on every PR and every push to `main`: `npm ci` → registry signature check → audit gate (fails on any advisory not explicitly accepted) → lint → build → unit tests. A separate dependency-review job runs on PRs. Actions are pinned by commit SHA, with read-only permissions.
- **Supply-chain hardening:**
  - `.npmrc`: `strict-allow-scripts`, `min-release-age=7`, `save-exact`, `engine-strict`.
  - `package.json` `allowScripts` denies install scripts for `esbuild`, `lmdb`, `msgpackr-extract`, `@parcel/watcher` and `fsevents`. Build, cache, watch mode, tests and the dev server were all verified to work without them.
  - `engines`: Node ^26.13.0, npm ^11.20.0, plus `.nvmrc` (26).

## Changed
- Version 0.2.0 in the workspace and library `package.json`. The library was 0.0.1, as generated.
- `.gitignore` allowlist: adds `projects/`, `eslint.config.js`, `.github/`, `.npmrc`, `.nvmrc`.

## Decided (built later, with the components)
- Built-in component text (EN/AR) comes from a **runtime label service**: the language switches without a rebuild, and white-label customers can override labels.
- Arabic/RTL foundations are already present: `@angular/cdk/bidi` and Arabic locale data in `@angular/common`.
- Docs site: our own Angular app using the real components, on GitHub Pages first, then WideBot self-hosting.

## Known gaps
- **Accepted advisory GHSA-g3hv-75wg-m249** (moderate, `minimatch` 10.2.6, via ESLint 10 / typescript-eslint). It's in lint tooling only and never ships in the design system. npm's "fix" would downgrade ESLint to 9. It's removed once ESLint ships on `minimatch` ≥11.0.1 past the 7-day rule.
- **Unit tests are skipped in CI while the library has no test files** (`ng test` errors with zero tests). They become mandatory at the first component.
- **CI hasn't run on GitHub/Linux before this PR.**
- The Angular CLI MCP server's gaps (carried over from v0.1.0).
- No branch rules on `main` yet. They come after CI passes on GitHub.
