# v0.2.1

**Date:** 2026-11-08, 01:50 EET (UTC+02:00)
**Goal achieved:** `main` is protected, and CI runs on a fixed OS. This is the first release merged under the branch rules.

## Changed
- CI runner pinned to `ubuntu-24.04` (both jobs). It was `ubuntu-latest`, which GitHub is moving to Ubuntu 26 from 2026-10-19. 24.04 is the image every CI run so far has used (image release `ubuntu24/20261101.360`).
- Version 0.2.1 (workspace + library).

## Repository settings (outside the code)
- **Ruleset "main: PR + CI required"** (id 26778478), active on the default branch since 2026-11-08 01:45 EET:
  - a PR is required (0 approvals: one maintainer, and CI is the gate); review threads must be resolved; merge commits only
  - required checks, which must come from GitHub Actions: "Install, audit, lint, build, test" and "Dependency review"; the branch must be up to date with `main`
  - no force-push, no deletion of `main`, no bypass (admins included)

## Known gaps
- GitHub added `require_extra_approval_for_unattributed_changes: true` to the PR rule by default. It isn't in GitHub's public docs, and its effect is being observed on this PR.
- Carried over from v0.2.0: the accepted advisory GHSA-g3hv-75wg-m249 (`minimatch`, lint tooling only); unit tests are skipped until the first component; the Angular CLI MCP gaps; some transitive packages have a low OpenSSF Scorecard (warnings).
