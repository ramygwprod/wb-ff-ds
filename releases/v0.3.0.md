# v0.3.0

**Date:** 2026-11-08, 02:15 EET (UTC+02:00)
**Goal achieved:** the docs site pipeline. The **Ferrofluid Design System** site (`ferrofluid-ds`) is an Angular app in the workspace that consumes the `wb-ff-ds` library. CI checks it on every PR, and every merge to `main` deploys it to GitHub Pages. The site is an empty shell for now: real pages come with the first components.

## Added
- **Docs app `ferrofluid-ds`** (`projects/ferrofluid-ds`), from `ng generate application` with Angular's defaults: routing, CSS, no SSR, zoneless, prefix `app`.
  - Angular's sample content was removed: the placeholder welcome page, the Angular-logo favicon, the sample "Hello" title test, and the unused `title` signal. The page is `<router-outlet />`, titled "Ferrofluid Design System".
  - It keeps Angular's own smoke test ("should create the app"), so CI now runs real unit tests.
  - Lint config for the app comes from angular-eslint, generated automatically.
- **Pages deployment** (`.github/workflows/pages.yml`), on pushes to `main` only: install → build library → build site with the base path from Pages (`/wb-ff-ds/`) → `404.html` SPA fallback → upload → deploy.
  - Actions are pinned by SHA: configure-pages v6.0.0, upload-pages-artifact v5.0.0, deploy-pages v5.0.1 (plus checkout and setup-node, as in CI).
  - Only the deploy job gets `pages: write` and `id-token: write`. Deployments never cancel each other.

## Changed
- **CI** builds each project explicitly (`ng build` needs a project name now that there are two): library first, then the site. Tests run per project, and a project with no test files is skipped with a notice (the library, for now).
- Version 0.3.0 (workspace + library).

## Repository settings (outside the code)
- GitHub Pages enabled with **GitHub Actions** as the source (needed before this release's first deploy).

## Known gaps
- The site is **public** on GitHub Pages until it moves to WideBot self-hosting (decided). There's no password until then.
- The site has no content yet, and no favicon until the brand assets exist.
- Carried over: the accepted advisory GHSA-g3hv-75wg-m249 (lint tooling only); library tests skipped until its first component; the Angular CLI MCP gaps; low-Scorecard transitive packages (warnings).
