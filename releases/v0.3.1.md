# v0.3.1

**Date:** 2026-11-08, 02:49 EET (UTC+02:00)
**Goal achieved:** the setup is documented and the commands are consistent. `package.json` scripts work in the two-project workspace, and CI, Pages, agents and people all run the same scripts. `CLAUDE.md` holds the project's rules, and the repo has a public README. The setup phase is complete.

## Added
- **README.md** (public): what the repo is, a link to the live docs, status, contents, goals, getting started, how changes land, and the licence (not decided yet).
- **`.prettierignore`**: protects `.claude/skills/` (vendored, hash-pinned), `releases/` (published changelogs are never rewritten) and `package-lock.json`.
- **CI "Format check" gate** (`npm run format:check`).

## Changed
- **`package.json` scripts**, rewritten for two projects. Angular's defaults (`start`, `build`, `watch`, `test`) all failed with "Cannot determine project". Now: `start`, `build` (= `build:lib` + `build:docs`), `build:lib`, `build:docs`, `watch:lib`, `test`, `lint`, `format`, `format:check`.
- **CI and Pages** call the npm scripts instead of their own `ng` commands, so nothing can drift. CI's per-project test loop stays until the library has tests.
- **`CLAUDE.md`**, rewritten for this project: what it is, the operating contract, commands, standards, supply chain, and releases. Angular's generated best practices are kept word for word, except **"WCAG AA minimums" → "WCAG AA and AAA"** (the two switchable theme levels).
- `eslint.config.js`: formatted to the project's Prettier style (quotes only; rules unchanged).
- Version 0.3.1 (workspace + library).
