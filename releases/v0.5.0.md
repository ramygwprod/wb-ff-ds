# v0.5.0

**Date:** 2026-11-15, 00:26 EET (UTC+02:00)
**Goal achieved:** the layout foundation has its agent. The agent is defined by a manifest that the hooks enforce; its knowledge now covers every recorded layout decision; and every name in it comes from a standard, so a developer or an AI agent can read it without a glossary. The agent has not run live yet (see Known gaps).

## Added

### The layout agent

- **Manifest** `knowledge-base/foundations/layout/agent.json`, the first real one:
  - **Name:** `layout`, the assignee for every layout and spacing task.
  - **Tools:** read, search, edit, and read-only web. No Bash.
  - **Write scope:** the layout `rules.json` and `sources.json` only.
  - **Finish gate:** `registry:check`, with two retries.

### Layout knowledge

- **Rules: 63 → 86**, in 10 groups. 23 are new and 28 existing ones were reworded. Six are marked `proposed`, each waiting on a named open decision.
  - **New group, "Containers and panes":** measuring on the nearest query container, minimum and maximum sizes, pushing, what gives way, stretch-fit and fit-content, and the three sizes of a control (content, box, target).
  - **Stale rules corrected:** the fluid range (L-T3, L-T10) and density as two settings (L-D1).
  - **Token names** (L-T20) and **density level names** (L-D14).
- **Sources: 62 → 70.** The eight new ones: WCAG 2.5.7, the APG Window Splitter pattern, CSS Images 3, CSS Overflow 3, Angular's image guide, two sets of Material pages (as learning references), and the Claude Code desktop docs. One mismatch was found by reading a source: the W3C page-structure tutorial does not cover skip links, so the skip-link rule (L-S2) now rests on WCAG 2.4.1 alone.
- **Decisions: 43 → 96**, with 80 answered and 16 open. Open questions that had lived only in conversation are now in the register, so an agent can see they are undecided.

### Naming from the standards

- **The rule** (DEC-061, DEC-086, DEC-093, DEC-096, in L-T19): names come from the DOM, HTML, CSS, ARIA and Angular, never from another design system; a standard term is never reused for something else; any developer or agent must read a name as the standard term, with no glossary.
- **Names replaced** (DEC-088):

  | Was | Now | From |
  | --- | --- | --- |
  | inset (for padding), stack, inline | `padding-block`, `padding-inline`, `row-gap`, `column-gap`, `margin-block`, `margin-inline` | CSS |
  | layer | in-flow, with stacking order | CSS Display 3, CSS Positioned Layout 4 |
  | floor | minimum | WCAG 2.2, CSS |
  | hug, fill | fit-content, stretch-fit | CSS Box Sizing 3 |
  | divider | window splitter | WAI-ARIA Authoring Practices |
  | compliance | conformance | WCAG 2.2 |
  | floating | overlay | Angular CDK |
  | shell | page layout, page regions | WAI tutorial, APG |

- **Primitives** (DEC-089) are CSS layout mechanisms, named as CSS names them: flex column, flex row, grid, scroll container and aspect-ratio box. A sidebar and the page layout are compounds and are not part of the foundation layer.
- **Token names** (DEC-023, DEC-091, DEC-092, DEC-094): three groups, `size`, `spacing` and `layout`. The nine sizes are `size.1` to `size.9`; the formula's parameters are `size.step`, `size.growth-ratio`, `size.range-start` and `size.range-end`; every other token is named after the CSS property it feeds.
- **Density levels** (DEC-094, DEC-095): `less`, `normal` and `more`. A default is a choice of level, not a level.
- **Component container** (DEC-090): the name for what frames a component. A bare "container" always means a query container.

### Pipeline

- **New script `registry:format`:** formats the knowledge base. Agents have no shell, so they cannot run Prettier themselves.
- **Finish gate:** now formats, then regenerates, then runs the manifest's checks.
- **Generated agent file:**
  - Proposed guidance is listed apart from guidance to apply, marked "don't apply", with the decision it waits on.
  - A foundation agent's open decisions now include its foundation's gaps: questions that have no rule yet.

## Known gaps

- **The layout agent has not run live.** Claude Code loads agent files when a session starts. Its first task is ready: verify the 15 cited sources that were never read.
- **47 of 57 check rules have no check yet.** They wait for the token contract and for Playwright (DEC-043).
- **No reviewer agents yet** (accessibility, RTL), so the manifest names none.
- **Every rule is a draft or a proposal.** Approval is this release's review.
- **16 decisions are open.** Among them:
  - **Values:** the nine sizes and the exact formula (DEC-073), container limits (DEC-022).
  - **Density:** what each setting adjusts (DEC-069), and whether the two are linked (DEC-074).
  - **Held for typography:** whether spacing follows the browser text size (DEC-071).
  - **Held until after the foundations:** control height (DEC-072) and the padding of a container with no text (DEC-078).
  - **Colour:** DEC-029 and DEC-042.
- **Carried over:** the accepted advisory GHSA-g3hv-75wg-m249; library tests stay skipped until its first component.
