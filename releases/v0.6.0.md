# v0.6.0

**Date:** 2026-11-15, 20:40 EET (UTC+02:00)
**Goal achieved:** the typography foundation has its agent and its decisions. The font families, sizes, weights, line heights, underline and font loading are decided, each on measured evidence, and the default fonts are installed as packages. Nothing uses the fonts yet, and the agent has not run live (see Known gaps).

### What was decided

| Decision | What it settles |
| --- | --- |
| DEC-098 | A use case of text is the HTML element that carries it, chosen by what the text is |
| DEC-099, DEC-106 | Font weight follows importance. Three levels, each identified by its weight: 600, 500 and 400 |
| DEC-100 | Font size, font weight, colour and white space tell use cases apart when they share a face |
| DEC-101 | Colour belongs to the colour foundation, after typography |
| DEC-102 | Each font's files are read for the faces they hold, and a missing value maps to the closest face |
| DEC-103 | A component keeps one block size in both languages: the space moves between the block padding and the line box |
| DEC-104, DEC-115 | Default families are shipped, and a tenant can replace them: Rubik for English and Arabic, IBM Plex Mono for code |
| DEC-105, DEC-111 | Eight font sizes, named by the CSS absolute-size keywords. The four largest grow with the query container |
| DEC-107 | One line height per size in English; 2 at every size in Arabic. The space between paragraphs follows the text's own line box |
| DEC-108 | The digits shown in Arabic are a setting of the tenant or the user. The default is Latin digits |
| DEC-109 | The browser never synthesizes a face the family lacks |
| DEC-110 | A font's width is not used |
| DEC-112, DEC-117 | Font files are served with the application, and only the faces in use: WOFF2, one file per weight, style and script |
| DEC-113 | A font's built-in metrics are left as shipped; only `line-height` is set |
| DEC-114 | Under Arabic text the underline is moved below the baseline; English keeps the browser's default |
| DEC-116 | `font-display: swap` |
| DEC-119 | Text falls back to the browser's standard font, which the user sets |
| DEC-071 | Under the browser's font-size setting, block-axis spacing grows with the text and inline-axis spacing stays fixed |

Two decisions govern how the knowledge base is written:

- **DEC-097:** an artifact carries only the standards' own terms, with their source. Meaning and objective are discussed with the owner, and that wording is never written into an artifact.
- **DEC-120:** a value the design system chooses lives in one central place. A rule says what must hold and points to that place; it never restates the value.

### The evidence behind the values

- **Line heights.** Measured in macOS's text engine and in Chrome 156, with the same figures to three decimals, at weights 400 to 700. As the smallest line height that keeps the ink inside its own line box, Rubik needs 1.13 to 1.15 for English. For Arabic it needs 1.48 to 1.55 with no vowel marks, and 1.93 to 1.97 with a mark under a deep letter.
- **Spacing under the browser's font-size setting.** A sample page in English and Arabic, at three widths and at 150 and 200 percent text. No option clipped text. With all spacing growing the page was 5 to 20 percent taller; with all spacing fixed the gap between paragraphs fell to half the font size.
- **The underline.** Rendered in Chrome 156: the browser's default line is broken by every Arabic descender.
- **A font swap.** A block changes height only when its line count changes, which was rare. A button is 3 to 10 percent wider in English.
- **The font files.** The prepared WOFF2 files were drawn beside the TrueType files they replace: 96 test strings measured the same.

## Known gaps

- **Neither agent has run live.** Claude Code loads agent files when a session starts. Live runs come after the foundation phase.
- **Nothing uses the fonts.** No stylesheet declares the faces and nothing copies the files into the library. The library is built after the foundations.
- **There is no token file yet.** Until the token contract exists (DEC-026), a chosen value lives in the decision that set it. The layout rules still restate values: DEC-120 is not applied to them yet.
- **77 of 87 check rules have no check yet:** 47 in layout and all 30 in typography.
- **Latin Extended is not included.** The Latin files hold Basic Latin and Latin-1, which covers English and French except the capital Ÿ.
- **Fallback fonts were measured on macOS only** (DEC-116).
- **Five typography sources were read through a summarising fetch.** Each says so in its note.
- **Every rule is a draft or a proposal.** Approval is this release's review.
- **16 decisions are open.** Typography's own is DEC-118 (tokens for text values the standard token type does not hold). Two are shared: the height of a control (DEC-072) and where preferences are stored (DEC-057). The rest belong to layout and colour.
- **Carried over:** the accepted advisory GHSA-g3hv-75wg-m249; library tests stay skipped until its first component.
